# html-note

Claude Code skill：長結論不要倒進聊天視窗：超過 30 行的交付物一律出成好讀的 HTML，只回一個網址加三行重點。

## 解決什麼問題

一份分析做完，六十行結論貼進對話——**看起來交付了，其實沒有**。

對方常在手機或平板上看，長訊息滑不動、抓不到重點；隔天想回頭找也翻不到。
而且**不會有人告訴你「我沒看」**，你會以為講完了。

## 怎麼解

1. **結論先行**：開頭就是三行重點，細節放後面
2. **每一頁都要有「要你決定什麼」那一段**——二選一：「現在球在你這裡的是 X」或「不需要你做事，只是回報 Y」
3. **同一份東西改版要回到同一個網址**，並在網址後加 `?v=2`，否則對方的瀏覽器給他舊版
4. **配一個 hook 自動提醒**——這支有效的原因不是有規矩，是不靠人記得

## 用法

安裝後，在對話裡講出觸發語即可：

```
給我看 / 整理一份報告 / 寫個計畫（或任何超過 30 行的交付物）
```

## 建議當範本改，不要照抄

這支是從真實工作長出來的，裡面的「踩過的雷」有些直接通用
（例如「只端一個方案等於替人做決定」），有些綁定特定工具，請換成你自己的。

**skill 真正值錢的不是步驟，是雷。** 步驟誰都想得到，雷想不到。
