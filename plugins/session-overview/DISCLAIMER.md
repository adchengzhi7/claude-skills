## English

A personal-productivity Claude Code mod.

- It runs inside the Claude Code process. This one only reads usage figures and the subagent list, and draws a pane; read the source before installing any mod.
- It registers one model-callable tool, `mcp__session-overview__panel`, which can only open, close or report the pane.
- Mods are early access; a Claude Code update may break it, in which case the engine skips it.
