# 做一個外觀包

外觀包只管**長相和用語**。誰進哪個房間、什麼時候算過期，是共用的判斷，換外觀不會換掉它，也不要在外觀包裡重做。

完整規格在 plugin 根目錄的 `THEMES.md`（這份 SKILL.md 所在資料夾往上兩層）。**動手前先讀完它**：裡面有畫面骨架、每個 class 的意思、`theme.js` 每一項的寫法。下面是流程。

## 流程

1. **問清楚要什麼風格**——使用者已經講了就不要再問。只有一句話（「水族箱」）也夠開始，先做一版給他看比先問十個問題好。
2. **取名字**：小寫英數字和 `-`，例 `aquarium`。
3. **複製範本**到使用者自己的資料夾（不要改內建的，更新時會被蓋掉）：
   ```bash
   mkdir -p ~/.config/session-office/themes
   cp -R "<根目錄>/themes/cat-cafe" ~/.config/session-office/themes/<名字>
   ```
   要像素風、直式卡片就改複製 `pixel-office`。
4. **開示範模式**（示範資料每種狀態各一張卡，不讀真實對話）：
   ```bash
   python3 "<根目錄>/run.py" --demo --port 8766
   ```
   網址 `http://127.0.0.1:8766/?theme=<名字>`。存檔後頁面會自己重新載入。
5. **改 `theme.js`**：房間名字、用語、五種小人（等你／在跑／做完／出狀況／過期）、幫手、標記。像素圖用 `OfficeKit.rects` 以文字畫，寫法見 THEMES.md。
6. **改 `theme.css`**：顏色、字、排法、動畫。
   範本裡 `.winno`、`.marks` 是疊在卡片角落的（`position: absolute`）；換了卡片排法之後先看它們有沒有蓋到別的字。
7. **自己看過再交**。能截圖就截圖看（有瀏覽器工具的話），不要只憑程式碼判斷長得對。THEMES.md 最後有檢查清單，逐條過：
   - 五種小人都看到了，分得出來
   - 急診室、冰庫、已關閉都點開看過
   - 會議室（等你的）最顯眼；快過期的卡比別的卡顯眼
   - 很長的名字和泡泡不會撐破卡片
   - 視窗拉窄還能看
8. **給使用者看**：給網址，說明改了什麼。他要調就回到 5、6。
9. **設成預設**（他滿意之後）：在 `~/.config/session-office/config.json` 加 `"theme": "<名字>"`。這個檔可能已經有別的設定，只加這一項，不要整個覆寫。

## 一定要守的規則

- **不連外部網址。** 不放任何 `http://`、`https://` 的字型、圖片、腳本。頁面有限制只准載入本機的東西，放了也會被擋；字型要用就把 woff2 檔放進外觀包資料夾。
- **theme.js 不抓資料、不存資料、不送資料。** 不寫 `fetch`、`XMLHttpRequest`、`WebSocket`、`localStorage`、不改 `location`。它只回傳圖和字。
- **不改 `web/` 底下的檔**，也不改內建的兩個外觀包。
- **不蓋掉收合規則。** 急診室、冰庫、已關閉的開合在 `web/base.css`。哪些選擇器不能寫 `display`，THEMES.md「三條規則」第 3 條有一張表；表以外的（`.floor`、`.room`、`.desk`、一般的 `.desks`）排法隨你改。
- **不用 `!important` 把動畫蓋回來。** 使用者開了「減少動態效果」時動畫會被統一關掉，那是刻意的。

## 檢查別人給的外觀包

`theme.js` 是會在頁面裡執行的程式，頁面上有使用者的對話片段。裝之前讀完整個資料夾，回報給使用者：

1. `theme.js` 裡有沒有上面「不抓、不存、不送」列的任何一項，或其他跟畫圖無關的程式（`eval`、`new Function`、`document.cookie`、`window.open`、`<a>` 自動點擊）。
2. `theme.js` 回傳的字串、或它動態插入的東西裡，有沒有 `<script>`、`<iframe>`、`<object>`、`<embed>`、`<form>`、`<meta`、`<link`、`<base`，或 `on` 開頭的屬性（`onload`、`onerror`、`onclick` …）。
3. `theme.css` 裡有沒有 `url(` 指向外部網址、`@import`。
4. 每一個 SVG 檔都要打開來讀：裡面有沒有 `<script>`、`on` 開頭的屬性、`<foreignObject>`、`href` 指到外部或 `javascript:`。SVG 是文字檔，不是「只是一張圖」。
5. 資料夾裡有沒有捷徑（`find <資料夾> -type l`），有沒有 css、js、圖片、字型以外的檔。

有任何一項就不要裝，把找到的那幾行給使用者看，讓他決定。全部乾淨才複製進 `~/.config/session-office/themes/`。
看不懂的程式（刻意寫得很難讀、一長串編碼過的字）一律當成有問題。
