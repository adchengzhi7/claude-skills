# meeting-notes

把**語音自動轉的會議逐字稿**整理成結構化會議記錄。Claude Code plugin，**你不直接用、是給 Claude 用**。

---

## 用 vs 不用 的差別

iPhone（iOS 18+）語音備忘錄錄完會議會自動轉逐字稿 —— 但那是一坨沒標點、滿是「呃／那個」、還夾雜辨識錯字的文字。

**沒裝這個 plugin：**

> 你：把那坨逐字稿貼給 Claude，自己再交代一長串「幫我抓重點、列待辦、標負責人……」

**裝了之後：**

> 你：[貼上逐字稿]「整理會議記錄」
> Claude：[自動觸發 meeting-notes，輸出 → 會議摘要 / 決議事項 / 待辦清單（負責人・期限）/ 待釐清]

---

## 它會做什麼

輸入一段會議逐字稿，輸出固定四段結構：

1. **會議摘要** — 3–5 點
2. **決議事項** — 這場會「拍板」了什麼
3. **待辦清單** — 表格：事項 / 負責人 / 期限（沒講到的標「待確認」）
4. **待釐清** — 含糊處、疑似辨識錯字、該追問的點

核心原則：**不捏造逐字稿沒有的內容；不確定的地方標出來、不當事實。**

---

## 安裝

在你的 Claude Code 裡：

```
/plugin marketplace add adchengzhi7/claude-skills
/plugin install meeting-notes
```

純 prompt 能力，**不需要安裝任何相依套件**，跨平台（macOS / Windows / Linux 都可）。

---

## 這個 plugin 的定位

它是「**半自動**」工作流的成品 —— iPhone 自動轉稿（免費）+ 你手動貼 + plugin 整理。

下一步（MCP / 自動化）會把「逐字稿來源 → 整理 → 待辦進行事曆」整條串起來。
meeting-notes 是 Skill（個人）→ Plugin（團隊）→ MCP（生態系）這條路上的橋。
