# context-weather

Claude Code mod：輸入框上方多一列，用天氣告訴你這段對話的空間（context window）還剩多少。

## 解決什麼問題

對話空間快滿時，Claude Code 會自動整理（compact）對話，細節會掉。
問題是平常看不出「現在用到幾成」，等發現的時候往往已經整理完了。

這個 mod 把用量變成一眼看得懂的天氣，快滿時提醒一次，讓你自己挑時間收尾或交接。

## 長什麼樣

輸入框正上方多一列（數字是舉例）：

```
對話空間 晴 ████░░░░░░░░░░░░░░░░ 18%  183k / 1M  空間很夠，照最近的速度約還能 40 回合  [ 明細 ] [ 收起 ]
```

| 天氣 | 用量 | 那一列會說 |
|---|---|---|
| 晴 | 40% 以下 | 空間很夠 |
| 多雲 | 40–59% | 還夠用 |
| 陰 | 60–74% | 用掉一大半了 |
| 有雨 | 75–89% | 該找段落收尾了 |
| 暴雨 | 90% 以上 | 快滿了，先交接再繼續 |

- 跨進「有雨」和「暴雨」時各跳一次提醒；同一級不重複。對話整理過、用量降回去之後，下次再跨進來才會再提醒。
- 按「明細」會在旁邊打開一塊區域，由大到小列出是什麼在佔空間（對話內容、工具說明、記憶檔……），外加 5 小時／7 天額度。

## 需要什麼

- Claude Code 的 Mods 功能（2026 年 10 月推出，仍是 early access，API 還會變）。這個 mod 在 **2.1.288** 上開發與測試，更舊的版本沒試過。
- 終端機版或桌面版。
- 介面文字是繁體中文。

## 安裝

```
/plugin marketplace add adchengzhi7/claude-skills
/plugin install context-weather
```

裝完開一個新的 session。送出第一句話、Claude 回完之後，那一列才會有讀數（引擎在每回合結束時才量用量）。

想先試不想裝：把這個資料夾抓下來，用 `claude --plugin-dir <資料夾路徑>` 啟動，只對那一次生效。

## 用法

| 你做 | 結果 |
|---|---|
| 按「明細」，或打 `/context-weather` | 打開明細 |
| 按「收起」，或打 `/context-weather off` | 那一列消失 |
| 打 `/context-weather` | 那一列回來 |

## 它碰得到什麼

Mod 跑在 Claude Code 自己的程序裡，權限可以很大，裝任何 mod 之前都該先看這一段。
這一個只做三件事：讀用量、記住這個 session 的讀數、畫畫面。用到的引擎功能如下，可以自己跑 `claude plugin validate` 對照：

| 用到的 | 拿來做什麼 |
|---|---|
| `$.session.usage` | 讀對話空間用量與額度 |
| `$.state` | 記住這個 session 的讀數（不跨 session、不寫檔） |
| `$.ui.*` | 畫那一列、明細、提醒 |
| `$.command.register` | 註冊 `/context-weather` |

**沒有用到**：讀寫檔案、連網、執行外部程式、改你送出的訊息、攔截或改寫工具呼叫。

## 已知限制

- 那一列的百分比是對「模型的對話空間上限」算的；明細裡的百分比是對「自動整理的門檻」算的，而且是估算值。兩個數字可能不一樣。
- 「約還能幾回合」是照最近幾回合的成長速度粗估，至少要三次讀數才會出現；用量變小（整理過、清空過）就重新起算。
- 明細的項目名：認得的顯示中文，不認得的顯示 Claude Code 給的英文原名。
- 視窗窄於 100 欄會省略後面那句話，窄於 80 欄會省略長條。
- 只在主對話每回合結束時更新，回合進行中不會動。

## 測試

```
claude plugin validate plugins/context-weather
claude plugin test plugins/context-weather
```

5 個測試：顯示內容（終端機與桌面版）、提醒只跳一次且降回去後會重新提醒、預估回合數、明細排序、用量變小會重新起算。
