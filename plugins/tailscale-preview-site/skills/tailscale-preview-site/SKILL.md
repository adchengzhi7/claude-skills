# tailscale-preview-site

一個自己架的預覽站：**一台常開的機器 + 一個資料夾 + Tailscale 私網**。
把 HTML 丟進去，拿到一個網址，你自己的手機／平板／筆電打開就看得到，別人看不到。

## 為什麼要自己架

- **不用登入**。收件的人不需要辦帳號、不需要記得用哪個帳號登入。
- **手機平板直接看**。長報告在終端機裡讀很痛苦，在瀏覽器裡很好讀。
- **沒有第三方**。內容不會離開你的機器與你的 Tailscale 網路。

代價很誠實：**你得有一台常開的機器**（Mac mini、NAS、舊筆電都行）。沒有的話這隻 skill 幫不上忙。

## 第一次使用

還沒架站 → 讀 `SETUP.md`，十分鐘。
已經架好 → 往下看。

## 發佈一份頁面

```bash
{SKILL_DIR}/scripts/publish.sh <檔>.html \
  --title "首頁清單上的標題" \
  --desc  "一句話摘要（給未來的自己掃清單用）" \
  --meta  "YYYY-MM-DD · 專案 · 狀態" \
  [--also 附件.pdf]
```

腳本會做：檢查機器 → 清洗檔名 → 複製進站台資料夾 → **首頁插入或更新那一張卡片（其餘卡片絕不動）**
→ 重建全站頁面清單 → 確認站台活著（掉了自動重開）→ 印出網址。

`--meta` 的中間那段會**自動變成標籤**，所以填一致的專案名，首頁就能按專案篩選。

### 稿子不要直接寫在站台資料夾裡

寫在別的地方（暫存目錄、專案資料夾）再發佈。
直接寫在站台資料夾裡會被擋下來——因為複製步驟的來源與目的地相同會失敗，
結果是**頁面打得開、但首頁上沒有卡片**，你會在清單裡找不到它。

## 首頁怎麼用

- **搜尋框**：多個詞用空白隔開，全部命中才顯示（例如 `客戶 資安`）
- **標籤**：點一下按專案篩選，再點一下取消
- **`/`**：聚焦搜尋框
- **Cmd+K（或 Ctrl+K）**：全站搜尋面板，**包含沒有卡片的頁面**
- **未分類頁面**：首頁底部，收容所有沒有卡片的檔案

## 站台管理

```bash
{SKILL_DIR}/scripts/serve.sh status      # 活著沒、綁在哪、紀錄在哪
{SKILL_DIR}/scripts/serve.sh start|stop
{SKILL_DIR}/scripts/serve.sh install     # 開機自動啟動（macOS launchd）
```

## 寫頁面的要點

- 單欄 `max-width:720px`、字級 ≥15px —— 手機平板要能直接讀
- **結論先行**：開頭就是重點，細節放後面
- **明講讀的人要決定什麼**。報告最常見的失敗不是寫錯，是「列了一堆面向但沒說球在誰那裡」
- 檔名用連字號、帶日期、不含空格：`<主題>-<YYYYMMDD>.html`
- 深色底、不要刺眼的白底大紅

## 給外人看 —— 不要用這個站

這個站**沒有登入機制**。它安全的唯一原因是「只有你 Tailscale 網路裡的裝置連得到」。

所以要給客戶、窗口、合作對象看的時候，**走一個有登入的管道**（你們公司的內部平台、
需要帳號的分享服務、任何能指名給誰看的東西），不要想辦法把這個站打開給外面。

**特別是：不要對這個站開 Tailscale Funnel。** 三個理由：

1. **Funnel 沒有登入**。任何拿到網址的人都看得到。
2. **網址不是秘密**。Funnel 用的 `ts.net` 憑證會登記進 Certificate Transparency 公開紀錄，
   主機名稱是查得到的。「沒人知道網址」不是防護。
3. **不能只開一份**。首頁只是一份手工清單，不是門——沒列在清單上的檔案，
   直接打網址照樣打得開。開 Funnel 等於**整個資料夾公開**，不是你想給的那一頁。

## 這個站會慢慢變成雜物間 —— 定期清

這不是理論風險，是實際會發生的事：一開始只放預覽網頁，後來順手丟安裝檔、
匯出的 CSV、客戶報價的試算表進去傳檔，然後就忘了。**幾個月後裡面躺著你不會想公開的東西。**

清理的時候**不要只用一個訊號判斷**：

| 只看這個 | 會誤殺什麼 |
|---|---|
| 有沒有被其他頁面連到 | 你直接打網址開的簡報資料夾——沒有頁面連它，但你在用 |
| 有沒有被打開過 | 網頁用 JS 抓的資料檔——掃引用掃不到，但頁面靠它才能顯示 |

**兩個訊號都是「沒有」才動它，而且搬走不要刪**，附一份清單記錄每個檔原本在哪，
過一段時間確認沒事再刪。

存取紀錄在站台資料夾的 **`.server.err`**（不是 `.server.log`）——
`python -m http.server` 把存取紀錄寫到 stderr，看錯檔會以為沒有紀錄。

## 別做的事

- **不要綁 `0.0.0.0`**。那會讓同一個 Wi-Fi 下的所有裝置都連得進來。腳本會擋，別繞過。
- **不要整份重建首頁**。每張卡片的標題與摘要是人寫的，重建會洗掉。
- **不要改卡片的 HTML 寫法**。發佈腳本靠比對那個寫法來插入與更新，改了就壞。
- **不要把站台資料夾放在系統保護的目錄**（桌面、文件夾）。背景服務可能讀不到。
