# 使用前請讀

## 這個站沒有登入機制

它架起來的東西是一個**沒有任何身分驗證的靜態檔案伺服器**。
它之所以安全，唯一的原因是綁在 Tailscale 私網位址上，
只有你 Tailscale 網路裡的裝置連得到。

**這代表：**

- 你 Tailscale 網路裡的**每一台裝置**都看得到站上的**每一個檔案**——
  包含你分享進來的節點、公用電腦、店面機器。裝置不等於人：
  一台放在櫃檯的電腦，摸得到它的人都看得到你的站。
- 首頁的清單**不是門**。沒列在清單上的檔案，直接打網址一樣打得開。
- 沒有稽核紀錄以外的存取控制。誰看了什麼只能事後從紀錄推。

**開始用之前，先確認你的 Tailscale 網路裡有哪些裝置：**

```bash
tailscale status                # 有哪些裝置、屬於誰
tailscale debug netmap          # 實際生效的存取規則（比讀 ACL 原始檔準）
```

## 不要對它開 Tailscale Funnel

Funnel 會把站台開到公開網際網路，而且：

1. 沒有登入，任何拿到網址的人都看得到
2. `ts.net` 的 TLS 憑證會進入 Certificate Transparency 公開紀錄，主機名稱查得到——
   「網址沒人知道」不是防護
3. 不能只開一份，開了就是整個資料夾

要給外部對象看，請走有登入、能指名對象的管道。

## 不要放這些東西

站台資料夾很容易變成傳檔用的雜物間。**不要放**：

- 金鑰、憑證、`.env`、任何密碼
- 客戶個資、訂單與發票資料、報價與合約
- 安裝檔與可執行檔

如果你已經放了（很常見），照 `SKILL.md` 的清理章節處理。

## 沒有保固

這是一組工具腳本，不是產品。它會修改你設定的資料夾與 macOS 的 LaunchAgents。
用之前看一眼腳本在做什麼。作者不對任何資料遺失或資訊外洩負責。
