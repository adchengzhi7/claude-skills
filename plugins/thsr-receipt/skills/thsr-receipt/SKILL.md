# 台灣高鐵購票證明自動下載

從台灣高鐵官方系統（`ptis.thsrc.com.tw`）下載報帳用的購票證明 PDF，自動命名歸檔到 `~/Downloads/thsr_receipts/`。

## 適用範圍（v0.1）

- ✅ **磁票 / QR Code 紙票**：網路訂票後取票（自動售票機/超商/窗口）的票
- ⚠️ **T Express 行動票證**：v0.1 尚未支援，第二版會加
- ❌ **回數票/定期票**：不在範圍

## 觸發判斷

- 使用者說「下載高鐵購票證明」、「高鐵 receipt」、「報帳要的高鐵車票」
- 使用者貼出高鐵訂票確認 / 取票畫面截圖
- 使用者同時提供：訂位代號（8 碼英數）OR 車票號碼（13 碼數字）+ 乘車日 + 起站 + 訖站

## 必要資訊

| 欄位 | 範例 | 從哪取得 |
|---|---|---|
| 訂位代號 | `87654321`（8 碼數字）| T Express App / 訂票確認 |
| 車票號碼 | `1234567890123`（13 碼）| 取票後票面 / T Express |
| 乘車日期 | `2026-04-29` | 同上 |
| 起站 | `南港` | 票面 |
| 訖站 | `台中` | 票面 |
| 票種 | 對號座 / 自由座 | 通常是對號座 |
| **統編 + 公司名稱** | `12345678` / `好好谷倉股份有限公司` | **報帳必填**，從 `~/.config/thsr-receipt/companies.json` 或當場問使用者 |

## 重要：每次都要問使用者「請款給哪一家公司」

使用者可能對多家公司請款（自己的、客戶的、僱主的）。**不要假設用同一家**。

### 觸發後的標準流程

1. **先列出可選公司**：
   ```bash
   python3 ~/.claude/skills/thsr-receipt/scripts/download.py --list
   ```
   把結果列給使用者看。

2. **問使用者**：「這次要請款給哪一家？」
   - 使用者回答 label（例：「好好谷倉」）
   - 或直接給 `--tax-id` + `--company`（一次性）

3. **跑下載**：
   ```bash
   python3 ~/.claude/skills/thsr-receipt/scripts/download.py \
     --pnr 87654321 \
     --tid 1234567890123 \
     --date 2026-04-29 \
     --from 南港 --to 台中 \
     --company-label "好好谷倉"
   ```

### 公司清單檔案結構

`~/.config/thsr-receipt/companies.json`（**本機獨有，永遠不上 git**）：

```json
[
  {"label": "好好谷倉", "tax_id": "12345678", "name": "好好谷倉股份有限公司"},
  {"label": "客戶 A",   "tax_id": "87654321", "name": "AAA 顧問股份有限公司"}
]
```

如果使用者還沒建這個檔案，**第一次觸發時要引導他建立**：
- 問他：你最常請款的公司有哪些？（label + 統編 + 全名）
- 幫他寫進 `~/.config/thsr-receipt/companies.json`
- 之後就不用每次再問

## 執行步驟

### 1. 收集 5 個欄位

從使用者輸入或截圖讀出以上 5 項。**任一缺少就跟使用者問**，不要猜。

### 2. 跑下載腳本

```bash
python3 ~/.claude/skills/thsr-receipt/scripts/download.py \
  --code P5KW39C7 \
  --date 2026-04-15 \
  --from 台北 \
  --to 左營
```

選項：

| 旗標 | 說明 |
|---|---|
| `--code` | 訂位代號或車票號碼，腳本自動判斷 |
| `--date` | 乘車日期，YYYY-MM-DD |
| `--from`、`--to` | 起站 / 訖站中文名（台北 / 板橋 / 桃園 / 新竹 / 苗栗 / 台中 / 彰化 / 雲林 / 嘉義 / 台南 / 左營 / 南港）|
| `--seat-type` | `reserved`（對號座，預設）/ `free`（自由座）|

### 3. PDF 處理

下載完的 PDF 是**有密碼保護**的（高鐵規定），密碼是**乘車日期 8 位數字**（YYYYMMDD）。

腳本會：
- 把 PDF 存到 `~/Downloads/thsr_receipts/{乘車日}-{起站}-{訖站}-{訂位代號或車票號碼}.pdf`
- 在檔名旁邊（or 控制台）告訴使用者：「PDF 密碼：YYYYMMDD」
- 用 `open -R` 開檔案位置

### 4. 回報

告訴使用者：
- 檔案位置
- PDF 密碼是哪一天

## 限制與規定（高鐵官方）

- 只能查**前一年至前一日**的資料
- 前一日的資料要等**乘車次日中午 12:00 後**才能查
- 報稅扣抵用的證明**只能下載一次**（要存好別丟）
- 票價為 0 的票無法提供本服務

## 不在範圍內

- T Express 行動票（用 T Express App 直接買的）→ v0.2 再加
- 回數票 / 定期票 → 走另一個 tab，不在這個 skill
- 高鐵電子發票（不一樣的東西）→ 走 https://einvoice.nat.gov.tw
